## Running the notebooks

All notebooks use **local data paths** relative to the repo root
(`../../../data/`). Run from any working directory — the paths are set in the
"Paths" cell of each notebook.

Requirements: same Python environment as the rest of the repo (`uv sync` /
`make dev`). PySpark notebooks require Java 11 and ~40 GB RAM.
